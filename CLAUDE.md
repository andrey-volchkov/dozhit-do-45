**Главный документ проекта: [BIBLE.md](BIBLE.md).** Сюжет, персонажи, ружья, визуальный и звуковой язык, правила текста, иллюстрации и деплой описаны там. Любая работа сверяется с библией. Если решение расходится с ней, сначала правится библия, потом код и текст.

## Текущий этап
См. **[NEXT.md](NEXT.md)**: отзыв заказчика («не хватает погружения, ужать историю»), план переделки подачи и новая структура глав. Начинать с неё.

## Проект
«Выдержка» — интерактивное кино в браузере: жизнь киевского фотографа, 1905–1945. Статичный сайт для GitHub Pages, без сборщика и фреймворков.

## Устройство
- Сюжет пишется на Ink: `story/*.ink`. Все переменные игры лежат в `story/vars.ink`. Компилируется в `story.json`, который тоже коммитится.
- Движок: `js/*.js`, ES-модули, `inkjs` лежит в `vendor/`. Теги Ink работают как команды кинопроектора (список в BIBLE.md, «Техника»).
- Кадры: `img/<id>.jpg|png|webp`. Если файла нет, показывается «непроявленная пластина». Промпты Seedream лежат в `prompts/`.
- Звук синтезируется в Web Audio. Если в `audio/` есть файл с нужным id, берётся он.

## Команды
- `node tools/build.mjs` — компиляция Ink и проверка тегов и id кадров. Запускать перед каждым коммитом, который трогает `story/`.
- `node tools/walk.mjs --from ch01 --path 1,2,1` / `--check` — транскрипты веток и проверка тупиков.
- `node tools/play.mjs` — прогон в headless Chromium для плейтеста (сервер: `python3 -m http.server 8765`).

## Правила
- Текст по-русски, во втором лице, в настоящем времени. Правила текста в BIBLE.md §15 обязательны: никаких справок об истории и никаких голосов из будущего.
- Бюджет ограничен: пиши экономно, не читай большие файлы целиком без нужды.
- Работа идёт в ветке `claude/tender-mccarthy-jarwb5`, GitHub Pages публикует её корень. Перед пушем делать `git pull`: пользователь заливает кадры через веб-интерфейс.
